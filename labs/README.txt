BIO 116 · HRAS bioinformatics labs (4 self-contained HTML files)

  1-sequencing-assembly.html   Lab 1 · Sequencing & assembly
  2-gene-finding.html          Lab 2 · Gene finding
  3-genome-browser.html        Lab 3 · Genome browser (includes the graded exercise)
  4-genome-annotation.html     Lab 4 · Genome annotation

Keep all four files in the same folder: the "Lab n of 4" bar and the
previous/next links point to each other by file name.

Each file runs on its own in any modern browser. Fonts load from Google
Fonts when online and fall back to system fonts offline. Student progress
is saved in each student's own browser (localStorage).

Lab 3 graded exercise: "Submit and save file" downloads a JSON file for
students to upload to the course site.
