Five-Step ORF Finder

Write a short Python program that finds candidate genes (open reading frames) in the E. coli lac operon and translates them. Each step on this page builds one section of the program, in order. By the end you will have written find_orfs_beginner.py.

1Read a FASTA file and extract the sequence 2Make the complementary strand 3Write a regex that finds ORFs 4Search both strands, keep the longest ORFs in lists 5Translate each ORF with the genetic code

Input: data/J01636_lac_operon.fasta, the lac operon from GenBank J01636.1 (7,477 bp). It contains four genes: lacI, lacZ, lacY and lacA. Everything on this page runs the same steps as the Python program, on the same sequence.

1
Read the FASTA file

From file to one long string

A FASTA file has one header line that starts with >, then the sequence split over many lines. The program reads all the lines into a list, then goes through the list: it skips the header and joins the other lines into one string.

with opens the file and closes it again automatically at the end of the indented block. readlines() returns a list of strings, one per line, and each still ends in "\n".

with open("data/J01636_lac_operon.fasta") as fasta_file:
    lines = fasta_file.readlines()

print("Lines in the file:", len(lines))
print("First line:", lines[0].strip())

sequence = ""
for line in lines:
    line = line.strip()              # remove the "\n" at the end
    if line.startswith(">"):         # header line: skip it
        continue
    sequence = sequence + line.upper()
# (For a whole genome, collect the lines in a list and use "".join(list) instead: it is much faster.)

print("Sequence length:", len(sequence), "bases")

Discussion

Without skipping the header, its letters (J01636.1 E.COLI…) would become part of the sequence. Every line ends with a newline character, and .strip() removes it, along with the \r in files saved on Windows. .upper() handles lowercase files. Spaces, numbers, U or N in the sequence get through step 1 but crash step 2, because the pairing dictionary has no entry for them. Two records in one file are joined without any error, which is the most dangerous case: the program runs but the answer is wrong.

The complementary strand

      
Pair every base, then read it backwards

    

    

      

        
DNA has two strands. Each base pairs with a partner, A with T and C with G, and the two strands run in opposite directions. Genes can be on either strand, so the program needs both.

        
A dictionary stores the pairs. The loop looks up each base's partner, then [::-1] reverses the result so the other strand also reads 5′ to 3′, the direction the ribosome reads.

        
pairs = {"A": "T", "T": "A", "C": "G", "G": "C"}

complement = ""
for base in sequence:
    complement = complement + pairs[base]

reverse_complement = complement[::-1]    # [::-1] reverses a string

The first base of sequence pairs with the last base of reverse_complement. A letter that is not a key in the dictionary raises KeyError and stops the program.

          

        

      

      

        
        
        

        

      

    

  


  
  

    

      
3

      
A regular expression for ORFs

      
Build the pattern one piece at a time

    

    

      

        
An ORF is a start codon, then codons, then a stop codon, all in the same reading frame. Click the buttons a to f in order. Each adds one idea, and the bench shows what that pattern finds on the lac sequence. The ORF check column tests each match: length divisible by 3, ATG first, a stop last, no stop in between.

        
#   ATG                        start codon
#   (?:(?!TAA|TAG|TGA)...)     one codon (any 3 bases) that is NOT a stop codon
#   {100,}                     at least 100 of those codons
#   (?:TAA|TAG|TGA)            stop codon: the first one in the same frame
#   (?=( ... ))                lookahead: lets ORFs overlap, so none are missed;
#                              the ORF itself is saved in group 1

orf_pattern = r"(?=(ATG(?:(?!TAA|TAG|TGA)...){100,}(?:TAA|TAG|TGA)))"

Discussion

            
... moves three bases at a time, so the stop is always in frame, but in c the lazy *? is the only thing that makes it stop at the first stop. In d the "not a stop" check does that job, so the length can be added safely in e. Without the lookahead, a regex search continues from the end of each match, so any ATG inside a match is never tried: the ORF at 12–329 hides the ATG at 202 where the lacI ORF begins. The lookahead in f matches without using up bases, so every ATG gets its turn.

4

      
Search both strands

      
Keep the longest ORF for each stop codon

    

    

      

        
The lookahead finds every ATG that starts an ORF, including ATGs inside a longer ORF in the same frame. Those end at the same stop codon, so they are shorter copies of the same ORF. Matches come in order from left to right, so the first ORF for each stop is the longest. The program remembers the stop positions it has used in the list stops_seen and skips repeats.

        
The results go into three lists that line up: item i of orfs, strands and starts all describe the same ORF.

        
orfs = []        # the ORF sequences
strands = []     # "+" or "-" for each ORF
starts = []      # start position of each ORF on its strand (counting from 1)

for strand in ["+", "-"]:
    if strand == "+":
        dna = sequence
    else:
        dna = reverse_complement

    stops_seen = []                          # stop positions already used on this strand
    for match in re.finditer(orf_pattern, dna):
        orf = match.group(1)
        stop_position = match.end(1)
        if stop_position in stops_seen:      # a shorter ORF inside one we already have
            continue
        stops_seen.append(stop_position)

        orfs.append(orf)
        strands.append(strand)
        starts.append(match.start(1) + 1)

print("ORFs found:", len(orfs))

Discussion

            
lacZ is over 3,000 bases long and has many ATGs in its own frame; each still has at least 100 codons before the same stop, so each one matches. Only the first, most upstream one is kept. Positions on the two strands are counted separately, so a stop position on one strand says nothing about the other. Python counts from 0, but biologists and GenBank count from 1. The inner ATGs are not useless: they are the other possible start codons, which matters when a gene does not start at the first ATG.

One codon at a time

    

    

      

        
The genetic code is a dictionary: each codon is a key, and its amino acid (one-letter code) is the value. * means stop. The loop goes through the lists with an index i, and steps through each ORF three bases at a time.

        
genetic_code = {
    "TTT": "F",  "TCT": "S",  "TAT": "Y",  "TGT": "C",

    "GTG": "V",  "GCG": "A",  "GAG": "E",  "GGG": "G",

for i in range(len(orfs)):

Discussion

          
lacI starts with GTG and lacA with TTG. Bacteria use these alternative start codons for some genes, and a regex that looks only for ATG cannot find them; it finds the next ATG in the same frame instead. The − strand ORFs are antisense to real genes: a long gene often hides long ORFs on the opposite strand, and they are not genes. A BLASTp hit to a known protein is the strongest single piece of evidence.

# Find candidate genes (ORFs) in the lac operon and translate them.
# Run from the repository root:  python3 find_orfs_beginner.py

import re


# ------------------------------------------------------------------
# Step 1: Read the FASTA file and extract the sequence
# ------------------------------------------------------------------
# A FASTA file has one header line that starts with ">",
# followed by lines of sequence. We skip the header and join the rest.

# "with" opens the file and closes it again automatically at the end of the block.
# readlines() gives a list of strings, one per line, each ending in "\n".
with open("data/J01636_lac_operon.fasta") as fasta_file:
    lines = fasta_file.readlines()

print("Lines in the file:", len(lines))
print("First line:", lines[0].strip())

sequence = ""
for line in lines:
    line = line.strip()              # remove the "\n" at the end
    if line.startswith(">"):         # header line: skip it
        continue
    sequence = sequence + line.upper()
# (For a whole genome, collect the lines in a list and use "".join(list) instead: it is much faster.)

print("Sequence length:", len(sequence), "bases")


# ------------------------------------------------------------------
# Step 2: Derive the complementary strand
# ------------------------------------------------------------------
# Each base pairs with its partner: A-T and C-G.
# The other strand runs in the opposite direction, so after
# complementing we reverse it to read it 5' to 3' like the first strand.

pairs = {"A": "T", "T": "A", "C": "G", "G": "C"}

complement = ""
for base in sequence:
    complement = complement + pairs[base]

reverse_complement = complement[::-1]    # [::-1] reverses a string


# ------------------------------------------------------------------
# Step 3: A regular expression that finds ORFs
# ------------------------------------------------------------------
#   ATG                        start codon
#   (?:(?!TAA|TAG|TGA)...)     one codon (any 3 bases) that is NOT a stop codon
#   {100,}                     at least 100 of those codons
#   (?:TAA|TAG|TGA)            stop codon: the first one in the same frame
#   (?=( ... ))                lookahead: lets ORFs overlap, so none are missed;
#                              the ORF itself is saved in group 1

orf_pattern = r"(?=(ATG(?:(?!TAA|TAG|TGA)...){100,}(?:TAA|TAG|TGA)))"


# ------------------------------------------------------------------
# Step 4: Search both strands and keep the longest ORF for each stop codon
# ------------------------------------------------------------------
# The lookahead also finds shorter ORFs that start at an ATG inside a
# longer one and end at the same stop codon. Matches come in order from
# left to right, so the first ORF we see for each stop is the longest.

orfs = []        # the ORF sequences
strands = []     # "+" or "-" for each ORF
starts = []      # start position of each ORF on its strand (counting from 1)

for strand in ["+", "-"]:
    if strand == "+":
        dna = sequence
    else:
        dna = reverse_complement

    stops_seen = []                          # stop positions already used on this strand
    for match in re.finditer(orf_pattern, dna):
        orf = match.group(1)
        stop_position = match.end(1)
        if stop_position in stops_seen:      # a shorter ORF inside one we already have
            continue
        stops_seen.append(stop_position)

        orfs.append(orf)
        strands.append(strand)
        starts.append(match.start(1) + 1)

print("ORFs found:", len(orfs))


# ------------------------------------------------------------------
# Step 5: Translate each ORF with the genetic code
# ------------------------------------------------------------------
# Genetic code: codon -> amino acid (one-letter code, * = stop).
# Laid out like the textbook table.

genetic_code = {
    "TTT": "F",  "TCT": "S",  "TAT": "Y",  "TGT": "C",
    "TTC": "F",  "TCC": "S",  "TAC": "Y",  "TGC": "C",
    "TTA": "L",  "TCA": "S",  "TAA": "*",  "TGA": "*",
    "TTG": "L",  "TCG": "S",  "TAG": "*",  "TGG": "W",

    "CTT": "L",  "CCT": "P",  "CAT": "H",  "CGT": "R",
    "CTC": "L",  "CCC": "P",  "CAC": "H",  "CGC": "R",
    "CTA": "L",  "CCA": "P",  "CAA": "Q",  "CGA": "R",
    "CTG": "L",  "CCG": "P",  "CAG": "Q",  "CGG": "R",

    "ATT": "I",  "ACT": "T",  "AAT": "N",  "AGT": "S",
    "ATC": "I",  "ACC": "T",  "AAC": "N",  "AGC": "S",
    "ATA": "I",  "ACA": "T",  "AAA": "K",  "AGA": "R",
    "ATG": "M",  "ACG": "T",  "AAG": "K",  "AGG": "R",

    "GTT": "V",  "GCT": "A",  "GAT": "D",  "GGT": "G",
    "GTC": "V",  "GCC": "A",  "GAC": "D",  "GGC": "G",
    "GTA": "V",  "GCA": "A",  "GAA": "E",  "GGA": "G",
    "GTG": "V",  "GCG": "A",  "GAG": "E",  "GGG": "G",
}

for i in range(len(orfs)):
    orf = orfs[i]

    protein = ""
    for position in range(0, len(orf), 3):   # step through the ORF one codon at a time
        codon = orf[position:position + 3]
        protein = protein + genetic_code[codon]

    print()
    print("ORF", i + 1, "on strand", strands[i], "starting at", starts[i])
    print("  length:", len(orf), "bases,", len(protein) - 1, "amino acids")
    print("  protein:", protein)
