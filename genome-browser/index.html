    Reading a gene model

    Almost every browser draws transcripts with the same visual grammar. Once you know it, you can read UCSC, Ensembl and IGV without a legend.

    Strand sets the reading direction

    A + strand gene is read left to right, with arrows pointing ›. A − strand gene is read right to left (‹). Its 5′ end, TSS and exon 1 sit at the highest coordinate, at the right-hand end.

    The sequence track shows the + strand

    Browsers print the forward (+) strand left to right. For a − strand gene you have to reverse-complement what you see. The start codon ATG appears as CAT.

    Transcripts vs genes

    One gene can make several transcripts (isoforms) through alternative splicing or different start sites. Dense display merges them onto one line; full display gives each isoform its own row.

    Two ways to count

    Browsers and most annotation files (GFF, GTF, VCF, SAM) number bases, starting at 1, and include both ends. BED and bigWig files number the gaps between bases, starting at 0: the start fence is exclusive, the end fence inclusive. Off-by-one errors in bioinformatics usually come from mixing the two.

    Try a range between 1,001,995 and 1,002,014. These bases are the start of LUMN1 exon 1.

    Real browsers

    They all use the same ideas: a coordinate search box, zoom and scroll, tracks with display modes, and clickable features. The main differences are which data they bundle and whether they show your own files.

    UCSC Genome Browser

    Hundreds of annotation tracks for human, mouse and many other assemblies. Track display modes are hide / dense / squish / pack / full. Includes BLAT sequence search and the Table Browser for downloading data.

    Use it for: exploring a locus with lots of public annotation layered together.

    Ensembl

    Gene-centred pages: transcripts, protein domains, orthologues, variants and regulation. Its Variant Effect Predictor (VEP) annotates variant consequences like the ones in this lab.

    Use it for: everything about one gene, plus comparative genomics.

    IGV

    The Integrative Genomics Viewer runs on your computer or in a web page and loads your files: BAM reads, VCF calls, bigWig signal.

    Use it for: checking your own alignments and variant calls read by read.

    NCBI Genome Data Viewer

    Tied to NCBI's RefSeq, dbSNP and ClinVar records, for many organisms.

    Use it for: jumping between a browser view and NCBI's gene and variant records.

    JBrowse 2

    An open-source browser many model-organism and lab websites embed. It also handles synteny and structural-variant views.

    Use it for: organism databases and custom project sites.

    Try it for real: the sickle-cell variant

    Repeat the lab's moves on the human genome in the UCSC Genome Browser.

    1. Open genome.ucsc.edu and choose Genome Browser, assembly Human GRCh38/hg38.
    2. Type HBB (β-globin) in the search box and pick the gene. Which chromosome is it on? Which way do the intron arrows point?
    3. Set the gene track to full. How many exons does the main HBB transcript have?
    4. Search rs334. Zoom until you can read bases and turn on a dbSNP track if it is hidden.
    5. HBB's coding strand changes the codon GAG (Glu) to GTG (Val). What change do you expect to see on the + strand the browser displays?
    Check your answers
    • HBB is on chromosome 11 (11p15.4), on the − strand. The arrows point left.
    • The canonical HBB transcript has 3 exons.
    • rs334 changes glutamate to valine: HbS, traditionally “Glu6Val” and p.Glu7Val in HGVS, which counts the initial Met.
    • Because HBB is on the − strand, the coding change A→T shows on the + strand as T→A. That is the same reverse-complement step as Mission 6.

    Glossary

    Assembly
    One version of a genome's reference sequence, for example GRCh38 (UCSC name hg38). Coordinates only make sense relative to an assembly.
    Track
    One horizontal layer of data drawn against the ruler, usually backed by one file.
    Strand (+ / −)
    Which DNA strand a feature is read from. + reads toward higher coordinates.
    Exon / intron
    Exons stay in the mature RNA; introns are spliced out, almost always starting with GT and ending with AG.
    UTR
    Untranslated region: exonic sequence before the start codon (5′) or after the stop codon (3′).
    CDS
    Coding sequence: the part of the transcript from start codon to stop codon.
    Isoform
    One of several transcripts made from the same gene, for example through exon skipping.
    Reading frame
    One of three ways to group a strand into codons. Six frames in total across both strands.
    Conservation
    How little a base has changed across species (e.g. phyloP, phastCons). High scores suggest function.
    Coverage
    How many sequencing reads overlap each base. In RNA-seq, it tracks expression.
    Missense / synonymous / nonsense
    A coding change that swaps an amino acid, keeps it the same, or creates a stop codon.
    0-based / 1-based
    Counting gaps between bases from 0 (BED) versus counting bases from 1 (browser display, GFF, VCF).
