Regex ORF Lab

A bacterial gene is easy to spot on paper: a start codon, a run of codons, then a stop. In this lab you teach Python to see the same thing, one regular expression at a time, and then translate what it finds into protein.

5' …AAAAAGGAGGTTAACGATG AAG ATT GCT GTC CTC GGG … GGT GAA TAACATAAAC… 3' M K I A V L G … G E * Shine-Dalgarno ↑ ↑ start ↑ stop

Every box marked Regex bench runs your pattern live on the sequence chosen in the top bar. JavaScript runs the patterns in the browser, but the syntax you need here is the same as Python's re module. Named groups written (?P<name>…) are converted for you.

1
Start codons

Find every ATG

The simplest regular expression is a literal string. ATG matches the three letters A, T, G wherever they occur.

Challenge: write a pattern that finds every start codon on the + strand. The checker turns green when your matches equal the true set.

# Python
import re
for m in re.finditer(r"ATG", seq):
    print(m.start(), m.start() % 3)   # position, reading frame
Predict, then check
  1. An ATG turns up by chance about once every 64 bases. How many would you expect in the teaching sequence? Compare with the bench.
  2. What does m.start() % 3 tell you, and why will it matter later?
  3. Is every ATG the start of a gene? What else has to be true?
Discussion

The teaching sequence is 469 nt, so chance alone predicts about 7 ATGs per strand. It has 3 on the + strand and 6 on the − strand (switch the bench to ±), because its spacer DNA was designed with few ATGs. The value of m.start() % 3 is the reading frame (0, 1 or 2). A start and a stop only belong to the same ORF when they share a frame. Most ATGs are not gene starts: they sit inside other genes, in the wrong frame, or are followed by a stop a few codons later.

2
Stop codons

One pattern, three stops

The pipe | means "or". Parentheses group alternatives, but in Python they also capture, which changes what re.findall returns.

Challenge: match TAA, TAG and TGA with a single pattern.

re.findall(r"TAA|TAG|TGA", seq)      # ['TAA', 'TGA', ...]
re.findall(r"T(AA|AG|GA)", seq)     # ['AA', 'GA', ...]  surprise!
re.findall(r"T(?:AA|AG|GA)", seq)   # ['TAA', 'TGA', ...]
Predict, then check
  1. Why does the second line return only two letters per hit? What does (?:…) change?
  2. Can two stop codons overlap each other, like TAAG? Try it on paper.
  3. The bench shows many stops. Why doesn't each one end a gene?
Discussion

When a pattern has a capturing group, findall returns the group, not the whole match. (?:…) groups without capturing. Stops cannot overlap: every stop starts with T, and no stop ends in T. A stop only ends an ORF when it is in the same frame as the start. The other two frames are full of stops that the ribosome never reads.

3
Putting start and stop together

Stay in frame

Now join the pieces: a start, some codons, a stop. Use the preset buttons to try the three attempts in order and watch the ORF check column. It tests each match for length divisible by 3, ATG at the front, a stop at the end, and no stop in between.

  • .* is greedy: it grabs as much as it can.
  • .*? is lazy: it stops at the first chance.
  • [ACGT]{3} is exactly one codon, so (?:[ACGT]{3})*? moves three bases at a time.

Challenge: every match must pass the ORF check, and you must find every one the reference finds.

orf_re = re.compile(r"ATG(?:[ACGT]{3})*?(?:TAA|TAG|TGA)")
for m in orf_re.finditer(seq):
    print(m.start(), len(m.group()) // 3, "codons")
Predict, then check
  1. Why does ATG.*(TAA|TAG|TGA) return one giant match?
  2. Switching to .*? makes the matches short. Why do they still fail the check?
  3. With the codon version, why does lazy *? guarantee there is no stop in the middle?
Discussion

Greedy .* runs to the end and backs up only to the last stop in the sequence. Lazy .*? takes the first stop it sees in any frame, so most matches have lengths that are not multiples of 3. Stepping by whole codons keeps the stop in frame, and laziness means the regex tries the stop at every codon, so it accepts the first in-frame stop.

4
Minimum length

Short ORFs are noise

Random DNA is full of short ORFs, so gene finders set a minimum length. Adding a count looks easy: change *? to {30,}?. Load The obvious fix and look for a red row.

A safer building block is a codon that is not a stop. The negative lookahead (?!TAA|TAG|TGA) checks the next three bases without consuming them.

Challenge: find ORFs with at least 30 codons between the ATG and the stop, with no internal stops.

CODON = r"(?:(?!TAA|TAG|TGA)[ACGT]{3})"   # any codon except a stop
orf_re = re.compile(r"ATG" + CODON + r"{30,}(?:TAA|TAG|TGA)")
Predict, then check
  1. Why does ATG(?:[ACGT]{3}){30,}?(?:TAA|TAG|TGA) run straight through a stop codon?
  2. Once stops are forbidden inside, does it matter whether the quantifier is greedy or lazy?
  3. Would you rather filter length with the regex or with len(orf) // 3 in Python? Why?
Discussion

{30,}? is lazy only after the first 30 codons. Those 30 can be anything, stops included. With stops forbidden inside, only one stop can end the match, so greedy and lazy give the same answer. Filtering in Python is easier to read and lets you change the cutoff without touching the pattern. Both approaches are fine.

5
Overlapping ORFs and the other strand

Six frames, nothing missed

re.finditer never returns overlapping matches. After a match it continues from the end, so an ORF that begins inside another one is skipped. Wrapping the pattern in a lookahead (?=( … )) makes every match zero-width, and the ORF is captured in group 1.

Genes on the other strand read in the opposite direction on the complementary bases. Set the bench to ± to search the reverse complement too. Coordinates in the table are always on the + strand.

Challenge: on both strands, find every ORF of any length, including ones that overlap or nest inside another. The starter is the step 3 pattern, which misses some.

def reverse_complement(seq):
    return seq.translate(str.maketrans("ACGT", "TGCA"))[::-1]

orf_re = re.compile(r"(?=(ATG(?:(?!TAA|TAG|TGA)[ACGT]{3})*(?:TAA|TAG|TGA)))")
for strand, s in (("+", seq), ("-", reverse_complement(seq))):
    for m in orf_re.finditer(s):
        orf = m.group(1)   # m.group(0) is empty
Predict, then check
  1. Run the step 3 pattern on the − strand of the teaching sequence. Which ORF does the lookahead version find that it missed?
  2. Several matches end at the same stop codon. How are they related, and which one would you report as the gene?
  3. An ORF sits at position 32 on the − strand of a 469 nt sequence. Where is it on the + strand?
Discussion

ORFs that share a stop are nested: each inner ATG gives a shorter version of the same reading frame. Gene finders usually keep the longest (most upstream start), then check for a Shine-Dalgarno sequence to choose the real start. For a match at start–end on the reverse complement of a sequence of length L, the + strand coordinates are L - end to L - start.

6
From codons to protein

Translate the candidates

Translation is a lookup: split the ORF into codons, look each one up in the genetic code, join the letters. A regex can do the splitting too.

BASES = "TCAG"
AMINO = "FFLLSSSSYY**CC*WLLLLPPPPHHQQRRRRIIIMTTTTNNKKSSRRVVVVAAAADDEEGGGG"
CODON_TABLE = {a + b + c: AMINO[16*i + 4*j + k]
               for i, a in enumerate(BASES)
               for j, b in enumerate(BASES)
               for k, c in enumerate(BASES)}

codons = re.findall(r"[ACGT]{3}", orf)
protein = "".join(CODON_TABLE[c] for c in codons)
Predict, then check
  1. Check the table: why does AMINO[16*i + 4*j + k] give the right amino acid? Look up TGG by hand.
  2. Every protein here ends in *. Should you keep it?
  3. Bacteria sometimes start at GTG. GTG normally codes for valine. What should the first residue be?
  4. What happens to CODON_TABLE[c] if the sequence contains an N?
Discussion

The string lists codons in TCAG order, with the first base changing slowest, so the index is a base-4 number. * marks the stop and is not a residue, so strip it before comparing with protein databases. A start codon is always read by the initiator tRNA, so GTG and TTG starts become fMet (M). An N raises KeyError. Use CODON_TABLE.get(c, "X") instead.

Put it together and push further

Your ORF finder

Write a script that reads frame 1 of triplets.txt, finds candidate genes of at least 100 codons on both strands, keeps the longest ORF per stop codon, and prints each with its translation. Try it yourself first. The reference answer is in the drawer below.

Extensions

  • Alternative starts. Change the start to (?:ATG|GTG|TTG). How many more ORFs appear?
  • Ribosome binding site. Use the bench to find a Shine-Dalgarno motif (AGGAGG) 4 to 12 bases upstream of an ATG. The checker is looking for both genes in the teaching sequence.
  • GC content. triplets.txt is about 66% GC. Stop codons are AT-rich. Predict whether long ORFs appear by chance more or less often in GC-rich DNA, then compare the ORF counts of the two sequences in step 6.

Reference script (open after you have tried) 
"""Find candidate bacterial genes (ORFs) with regular expressions and translate them."""
import re

MIN_CODONS = 100
BASES = "TCAG"
AMINO = "FFLLSSSSYY**CC*WLLLLPPPPHHQQRRRRIIIMTTTTNNKKSSRRVVVVAAAADDEEGGGG"
CODON_TABLE = {a + b + c: AMINO[16*i + 4*j + k]
               for i, a in enumerate(BASES)
               for j, b in enumerate(BASES)
               for k, c in enumerate(BASES)}

# start, then MIN_CODONS or more non-stop codons, then a stop; the lookahead allows overlaps
ORF_RE = re.compile(r"(?=(ATG(?:(?!TAA|TAG|TGA)[ACGT]{3}){%d,}(?:TAA|TAG|TGA)))" % MIN_CODONS)


def read_frame1(path):
    """Join the codons listed under 'start 1' in triplets.txt."""
    parts, in_block = [], False
    with open(path) as fh:
        for line in fh:
            if line.startswith("start"):
                if in_block:
                    break
                in_block = True
                continue
            parts.append(re.sub(r"[^ACGT]", "", line.upper()))
    return "".join(parts)


def reverse_complement(seq):
    return seq.translate(str.maketrans("ACGT", "TGCA"))[::-1]


def translate(orf):
    return "".join(CODON_TABLE.get(c, "X") for c in re.findall(r"[ACGT]{3}", orf))


def find_orfs(seq):
    length = len(seq)
    best = {}
    for strand, s in (("+", seq), ("-", reverse_complement(seq))):
        for m in ORF_RE.finditer(s):
            orf = m.group(1)
            start, end = m.start(1), m.start(1) + len(orf)
            # matches come left to right, so the first ORF seen for a stop is the longest
            best.setdefault((strand, end), (strand, start, end, orf))
    orfs = []
    for strand, start, end, orf in best.values():
        if strand == "-":
            start, end = length - end, length - start
        orfs.append((start + 1, end, strand, orf))   # 1-based, + strand coordinates
    return sorted(orfs)


if __name__ == "__main__":
    seq = read_frame1("triplets.txt")
    for start, end, strand, orf in find_orfs(seq):
        protein = translate(orf).rstrip("*")
        print(f"{start}-{end} ({strand})  {len(protein)} aa  {protein}")
