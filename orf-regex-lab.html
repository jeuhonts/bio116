Regex ORF Lab

A bacterial gene is easy to spot on paper: a start codon, a run of codons, then a stop. In this lab you teach Python to see the same thing, one regular expression at a time. You then translate what it finds and check every call against the GenBank annotation of the E. coli lac operon.

5' …TTTCACACAGGAAACAGCT ATG ACC ATG ATT ACG GAT TCA CTG … TGT CAA AAA TAA … 3' M T M I T D S L … C Q K * ↑ RBS ↑ start of lacZ (1284) ↑ stop (4358)

Every box marked Regex bench runs your pattern live on the sequence chosen in the top bar. JavaScript runs the patterns in the browser, but the syntax you need here is the same as Python's re module. Named groups written (?P<name>…) are converted for you.

1
Start codons

Find every ATG

The simplest regular expression is a literal string. ATG matches the three letters A, T, G wherever they occur.

Challenge: write a pattern that finds every ATG on the + strand. The checker turns green when your matches equal the true set.

# Python
import re
for m in re.finditer(r"ATG", seq):
    print(m.start(), m.start() % 3)   # position, reading frame
Predict, then check
  1. An ATG turns up by chance about once every 64 bases. How many would you expect in 7,477 bases? Compare with the bench.
  2. What does m.start() % 3 tell you, and why will it matter later?
  3. The record has four genes. Is every ATG the start of one? Does every gene start with ATG?
Discussion

Chance predicts about 117 ATGs per strand. The lac record has 135 on the + strand and 113 on the −. Only two of them, the starts of lacZ and lacY, begin a gene. The rest sit inside genes, in the wrong frame, or before a nearby stop. lacI starts at GTG and lacA at TTG, so no ATG search can ever find their real starts. The value of m.start() % 3 is the reading frame. A start and a stop only belong to the same ORF when they share a frame.

2
Stop codons

One pattern, three stops

The pipe | means "or". Parentheses group alternatives, but in Python they also capture, which changes what re.findall returns.

Challenge: match TAA, TAG and TGA with a single pattern.

re.findall(r"TAA|TAG|TGA", seq)      # ['TGA', 'TAA', ...]
re.findall(r"T(AA|AG|GA)", seq)     # ['GA', 'AA', ...]  surprise!
re.findall(r"T(?:AA|AG|GA)", seq)   # ['TGA', 'TAA', ...]
Predict, then check
  1. Why does the second line return only two letters per hit? What does (?:…) change?
  2. Can two stop codons overlap each other, like TAAG? Try it on paper.
  3. There are about 250 stops on the + strand, yet lacZ runs for over 3,000 bases. How?
Discussion

When a pattern has a capturing group, findall returns the group, not the whole match. (?:…) groups without capturing. Stops cannot overlap: every stop starts with T, and no stop ends in T. A stop only ends an ORF when it is in the same frame as the start. The stops scattered through lacZ are all in the other two frames, which the ribosome never reads.

3
Putting start and stop together

Stay in frame

Now join the pieces: a start, some codons, a stop. Use the preset buttons to try the three attempts in order and watch the ORF check column. It tests each match for length divisible by 3, ATG at the front, a stop at the end, and no stop in between. The GenBank column says whether a match is an annotated gene.

  • .* is greedy: it grabs as much as it can.
  • .*? is lazy: it stops at the first chance.
  • [ACGT]{3} is exactly one codon, so (?:[ACGT]{3})*? moves three bases at a time.

Challenge: every match must pass the ORF check, and you must find every one the reference finds.

orf_re = re.compile(r"ATG(?:[ACGT]{3})*?(?:TAA|TAG|TGA)")
for m in orf_re.finditer(seq):
    print(m.start(), len(m.group()) // 3, "codons")
Predict, then check
  1. Why does ATG.*(TAA|TAG|TGA) return one giant match?
  2. Switching to .*? makes the matches short. Why do they still fail the check?
  3. With the codon version, why does lazy *? guarantee there is no stop in the middle?
Discussion

Greedy .* runs to the end and backs up only to the last stop in the sequence. Lazy .*? takes the first stop it sees in any frame, so most matches have lengths that are not multiples of 3. Stepping by whole codons keeps the stop in frame, and laziness means the regex tries the stop at every codon, so it accepts the first in-frame stop.

4
Minimum length

Short ORFs are noise

Random DNA is full of short ORFs, so gene finders set a minimum length. Adding a count looks easy: change *? to {100,}?. Load The obvious fix and look for red rows.

A safer building block is a codon that is not a stop. The negative lookahead (?!TAA|TAG|TGA) checks the next three bases without consuming them.

Challenge: find ORFs with at least 100 codons between the ATG and the stop, with no internal stops.

CODON = r"(?:(?!TAA|TAG|TGA)[ACGT]{3})"   # any codon except a stop
orf_re = re.compile(r"ATG" + CODON + r"{100,}(?:TAA|TAG|TGA)")
Predict, then check
  1. Why does ATG(?:[ACGT]{3}){100,}?(?:TAA|TAG|TGA) run straight through stop codons?
  2. Once stops are forbidden inside, does it matter whether the quantifier is greedy or lazy?
  3. Look at the GenBank column. Which lac genes did you find, and are their coordinates right?
Discussion

{100,}? is lazy only after the first 100 codons. Those 100 can be anything, stops included. With stops forbidden inside, only one stop can end the match, so greedy and lazy give the same answer. On the + strand this pattern finds lacZ and lacY exactly, finds lacA with a start 6 bases too late (its real TTG start is invisible to an ATG pattern), and misses lacI entirely. Step 5 explains why.

5
Overlapping ORFs and the other strand

Six frames, nothing missed

re.finditer never returns overlapping matches. After a match it continues from the end, so an ORF that begins inside another one is skipped. Wrapping the pattern in a lookahead (?=( … )) makes every match zero-width, and the ORF is captured in group 1.

Genes on the other strand read in the opposite direction on the complementary bases. Set the bench to ± to search the reverse complement too. Coordinates in the table are always on the + strand, like GenBank's.

Challenge: on both strands, find every ORF of at least 100 codons, including ones that overlap or nest inside another.

def reverse_complement(seq):
    return seq.translate(str.maketrans("ACGT", "TGCA"))[::-1]

orf_re = re.compile(r"(?=(ATG(?:(?!TAA|TAG|TGA)[ACGT]{3}){100,}(?:TAA|TAG|TGA)))")
for strand, s in (("+", seq), ("-", reverse_complement(seq))):
    for m in orf_re.finditer(s):
        orf = m.group(1)   # m.group(0) is empty
Predict, then check
  1. The step 4 pattern missed lacI. Which ORF was in the way, and why does the lookahead fix it?
  2. Several matches end at the same stop codon. How are they related, and which one would you report?
  3. All four lac genes are on the + strand. What are the long ORFs on the − strand?
Discussion

An ORF at 12–329 overlaps the start of the lacI ORF (ATG at 202). finditer resumes at 330, past that ATG, so lacI disappears. ORFs that share a stop are nested: each inner ATG gives a shorter version of the same frame. Gene finders usually keep the longest, then check for an RBS (step 7). The − strand ORFs are antisense to real genes. A long gene often hides long ORFs on its opposite strand, and they are not genes.

6
From codons to protein

Translate the candidates

Translation is a lookup: split the ORF into codons, look each one up in the genetic code, join the letters. A regex can do the splitting too. Bacteria use translation table 11, which has the same codon meanings as the standard code.

BASES = "TCAG"
AMINO = "FFLLSSSSYY**CC*WLLLLPPPPHHQQRRRRIIIMTTTTNNKKSSRRVVVVAAAADDEEGGGG"
CODON_TABLE = {a + b + c: AMINO[16*i + 4*j + k]
               for i, a in enumerate(BASES)
               for j, b in enumerate(BASES)
               for k, c in enumerate(BASES)}

codons = re.findall(r"[ACGT]{3}", orf)
protein = "M" + "".join(CODON_TABLE[c] for c in codons[1:])
Predict, then check
  1. Check the table: why does AMINO[16*i + 4*j + k] give the right amino acid? Look up TGG by hand.
  2. Tick Allow GTG and TTG starts. What happens to lacI and lacA? Why is the first residue still M?
  3. With alternative starts, the longest ORF for lacI begins 9 bases before the annotated start. How could you tell which start is real?
  4. Every protein here ends in *. Should you keep it?
Discussion

The string lists codons in TCAG order, with the first base changing slowest, so the index is a base-4 number. A start codon is always read by the initiator tRNA, so GTG and TTG starts become fMet (M), which is why the code above writes "M" first. Allowing alternative starts recovers lacI and lacA, but "longest ORF" now picks an upstream GTG, 9 bases too early, for both. Sequence alone cannot settle it. The RBS in step 7 helps, and in the lab, protein sequencing does. * marks the stop and is not a residue. Use BLASTp this protein to confirm what you found.

7
Promoters and ribosome binding sites

Look upstream for evidence

An ORF is only a candidate. Real bacterial genes usually have a ribosome binding site (RBS) a few bases before the start codon, and a promoter somewhere upstream that RNA polymerase binds. Both are short sequences you can search for with regular expressions. This step asks how much each search tells you, using the lac record's annotation as the answer key.

A · The Shine-Dalgarno sequence

The 3' end of 16S rRNA pairs with a purine-rich motif, consensus AGGAGG, about 5 to 10 bases before the start codon. The spacing matters as much as the motif, so the pattern has to include the gap and the start codon.

Challenge: write a pattern that ends exactly at the annotated start codon of every lac gene that has a recognisable RBS. Start with the textbook consensus and see how far it gets you.

RBS_RE = re.compile(r"(?:GGAG|GAGG|AGGA)[ACGT]{4,12}(?:ATG|GTG|TTG)$")

def has_rbs(s, start):   # s = the strand the ORF is on
    # the $ forces the match to end exactly at this ORF's start codon
    return bool(RBS_RE.search(s[max(0, start - 30): start + 3]))
Predict, then check
  1. How many lac genes does AGGAGG[ACGT]{4,12}ATG find? What do their real RBSs look like?
  2. Why must the pattern end at the start codon instead of looking for the motif anywhere?
  3. In the picker below, what fraction of random start codons have an "RBS" by chance? Is an RBS proof of a gene?
Discussion

None of the lac genes has the full AGGAGG. lacZ and lacY have AGGA and lacA has GGAG, each 7 or 8 bases before the start. lacI has no recognisable RBS; it is translated poorly, which suits a repressor needed in only a few copies. A motif only works at the right distance from the start, so the regex anchors on the start codon. A loose core turns up before a few percent of random start codons, so an RBS raises confidence but proves nothing.

B · The σ70 promoter

Most E. coli housekeeping promoters have two boxes: TTGACA around −35 and TATAAT around −10, separated by 15 to 19 bases. As a regex:

r"TTGACA[ACGT]{15,19}TATAAT"

The lac promoter in this record has TTTACA at 1210 and TATGTT at 1234. The record also notes the UV5 mutant, where bases 1237–1238 change GT to AA and turn the −10 box into TATAAT. Use the slider to allow mismatches and watch two numbers: whether you catch the lac promoter, and how many chance hits appear.

from itertools import combinations

def fuzzy(box, k):
    """Regex for box with up to k mismatches: every way to put k wildcards in it."""
    options = ["".join("[ACGT]" if i in pos else b for i, b in enumerate(box))
               for pos in combinations(range(len(box)), k)]
    return "(?:" + "|".join(options) + ")"

promoter_re = re.compile("(?=(" + fuzzy("TTGACA", 2) + "[ACGT]{15,19}" + fuzzy("TATAAT", 2) + "))")
Predict, then check
  1. How many mismatches per box do you need to catch the wild-type lac promoter? And the UV5 mutant?
  2. At that setting, how many other hits are there in the 7.5 kb record? In random DNA per 10 kb?
  3. lacY and lacA have no promoter in front of them. How are they transcribed?
Discussion

The wild-type lac promoter differs from the consensus by 1 base at −35 and 2 at −10, so it needs 2 mismatches per box. It is deliberately weak and depends on CAP, whose binding site the record annotates at 1162–1199; the repressor binds the operator at 1246–1266. The UV5 mutant needs only 1 mismatch and is strong without CAP. At 2 mismatches the regex returns many other hits, so a regex cannot tell a real promoter from a random one. lacZ, lacY and lacA share one mRNA made from the lac promoter: that is what an operon is. Real tools score promoters with weight matrices and combine the score with other evidence.

"""Find candidate bacterial genes (ORFs) with regular expressions, translate them,
and compare each call with the CDS features of a GenBank record."""
import re

GENBANK_FILE = "data/J01636_lac_operon.gb"
MIN_CODONS = 100
STARTS = "ATG|GTG|TTG"   # try "ATG" to see which lac genes you lose

BASES = "TCAG"
AMINO = "FFLLSSSSYY**CC*WLLLLPPPPHHQQRRRRIIIMTTTTNNKKSSRRVVVVAAAADDEEGGGG"
CODON_TABLE = {a + b + c: AMINO[16*i + 4*j + k]
               for i, a in enumerate(BASES)
               for j, b in enumerate(BASES)
               for k, c in enumerate(BASES)}

# start, then MIN_CODONS or more non-stop codons, then a stop; the lookahead allows overlaps
ORF_RE = re.compile(r"(?=((?:%s)(?:(?!TAA|TAG|TGA)[ACGT]{3}){%d,}(?:TAA|TAG|TGA)))" % (STARTS, MIN_CODONS))
# Shine-Dalgarno core, a 4-12 base spacer, then the start codon at the very end
RBS_RE = re.compile(r"(?:GGAG|GAGG|AGGA)[ACGT]{4,12}(?:%s)$" % STARTS)
CDS_RE = re.compile(r"^ {5}CDS +(complement\()?<?(\d+)\.\.>?(\d+)\)?(.*?)(?=^ {5}\S|^ORIGIN)", re.M | re.S)


def read_genbank(path):
    """Return the sequence and a dict of CDS features {(strand, start, end): gene}."""
    with open(path) as fh:
        text = fh.read()
    origin = text.split("\nORIGIN", 1)[1].split("\n", 1)[1]   # skip the ORIGIN line itself
    seq = re.sub(r"[^ACGT]", "", origin.split("//")[0].upper())
    cds = {}
    for m in CDS_RE.finditer(text):
        gene = re.search(r'/gene="([^"]+)"', m.group(4))
        strand = "-" if m.group(1) else "+"
        cds[(strand, int(m.group(2)), int(m.group(3)))] = gene.group(1) if gene else "CDS"
    return seq, cds


def reverse_complement(seq):
    return seq.translate(str.maketrans("ACGT", "TGCA"))[::-1]


def translate(orf):
    codons = re.findall(r"[ACGT]{3}", orf)
    return "M" + "".join(CODON_TABLE.get(c, "X") for c in codons[1:])   # any start codon reads as fMet


def has_rbs(s, start):
    return bool(RBS_RE.search(s[max(0, start - 30): start + 3]))


def find_orfs(seq):
    """One ORF per stop codon: the most upstream start with an RBS, else the most upstream start."""
    length = len(seq)
    orfs = []
    for strand, s in (("+", seq), ("-", reverse_complement(seq))):
        starts_by_stop = {}
        for m in ORF_RE.finditer(s):
            starts_by_stop.setdefault(m.start(1) + len(m.group(1)), []).append(m.start(1))
        for end, starts in starts_by_stop.items():
            with_rbs = [p for p in starts if has_rbs(s, p)]
            start = with_rbs[0] if with_rbs else starts[0]
            orf = s[start:end]
            if strand == "+":
                a, b = start + 1, end                    # 1-based, like GenBank
            else:
                a, b = length - end + 1, length - start
            orfs.append((a, b, strand, orf, bool(with_rbs)))
    return sorted(orfs)


def compare(orf_call, cds):
    a, b, strand = orf_call[:3]
    if (strand, a, b) in cds:
        return "= " + cds[(strand, a, b)]
    for (cs, ca, cb), gene in cds.items():
        same_stop = cb == b if strand == "+" else ca == a
        if cs == strand and same_stop:
            return "~ %s (annotated %d..%d)" % (gene, ca, cb)
    return "not annotated"


if __name__ == "__main__":
    seq, cds = read_genbank(GENBANK_FILE)
    print("%d bp, %d annotated CDS" % (len(seq), len(cds)))
    for orf_call in find_orfs(seq):
        a, b, strand, orf, rbs = orf_call
        protein = translate(orf).rstrip("*")
        print("%5d..%-5d %s  %4d aa  RBS:%-3s  %-32s %s..." % (
            a, b, strand, len(protein), "yes" if rbs else "no", compare(orf_call, cds), protein[:20]))

Optional · Codon usage

      
Does it read like a gene?

    

    

      

        
Most amino acids have several codons, and each genome prefers some of them. E. coli uses CTG for about half its leucines and almost never uses AGG for arginine. A real gene read in its own frame is full of preferred codons. The same DNA read in any other frame is not.

        
So score each ORF by the average log frequency of its codons, then read the same stretch of DNA in the five other frames and score those too. If the ORF is a gene, its own frame should win. Comparing with other frames of the same DNA keeps the base composition identical, so only the codon pattern differs.

        
from collections import Counter
import math

SENSE = [a + b + c for a in "ACGT" for b in "ACGT" for c in "ACGT"
         if a + b + c not in ("TAA", "TAG", "TGA")]

def codon_table(genes):
    counts = Counter()
    for g in genes:
        counts.update(re.findall(r"[ACGT]{3}", g[3:-3]))   # skip start and stop
    total = sum(counts[c] + 1 for c in SENSE)                  # +1 so no codon has zero
    return {c: (counts[c] + 1) / total for c in SENSE}

def score(table, dna):
    codons = [c for c in re.findall(r"[ACGT]{3}", dna) if c in table]
    return sum(math.log(table[c]) for c in codons) / len(codons)

def six_frames(orf):
    anti = reverse_complement(orf)
    return {"own": orf, "+1": orf[1:], "+2": orf[2:],
            "anti 0": anti, "anti 1": anti[1:], "anti 2": anti[2:]}

# leave the gene being tested out of its own training set
table = codon_table([g for name, g in genes.items() if name != "lacY"])
scores = {f: score(table, dna) for f, dna in six_frames(genes["lacY"]).items()}

Discussion

            
CTG is about half of all leucine codons; AGA and AGG are rare arginine codons. Human genes use them more often, and E. coli has little of the matching tRNAs, which is a classic cause of poor expression of foreign proteins.

            
Random DNA with the same GC content is a weak comparison: an antisense ORF inside a real gene has almost the same composition as the gene, so it can score just as well. Other frames of the same DNA share its composition exactly, so only the codon pattern is tested.

            
On the lac record, at 100 codons with alternative starts: the lac frequency table puts all 4 genes in their own frame and rejects 6 of the 7 unannotated ORFs. The lac shares table drops to 3 of 4 genes (lacY fails) and 5 of 7. The genome shares table gets 4 of 4 and 5 of 7, but lacY and lacA win by tiny margins (0.001 and 0.003). The antisense ORF at 5988–6299, inside lacA, passes with both share tables.

            
Share tables ignore how common each amino acid is, which also differs between frames, so they lose part of the signal. The lac-trained tables come from only three genes, so they are noisy; the genome table averages thousands, including genes transferred from other species. The ORF at 6441–7118 lies outside the four annotated genes, so it may be a real neighbouring gene the record does not describe. BLAST its protein from step 6 to find out.
