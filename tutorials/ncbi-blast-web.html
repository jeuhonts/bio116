BLAST at NCBI

The Inside BLAST tutorial explained how the algorithm works. This one is practical: how to run protein BLAST on the NCBI website, what each setting does, and how to read the results page. All results shown here come from real searches run on NCBI's servers on 25 September 2026 with the same settings you will use. Do each exercise yourself alongside.

  • About 40 minutes, plus search time
  • Needs: a web browser; no account
  • Follows: Inside BLAST

  2. 2See furtherRaise "Max target sequences" and find what the default hid.

1

Getting started

  1. Go to blast.ncbi.nlm.nih.gov.
  2. Choose the program. You have a protein and want protein relatives, so click Protein BLAST (blastp). The other buttons are blastn (nucleotide), blastx (translated nucleotide query against proteins) and tblastn (protein query against translated nucleotides). The Inside BLAST tutorial explains when to use each.
  3. Have your query ready: a UniProt or NCBI accession, or the sequence itself. This tutorial uses human β-globin, P68871, and soybean leghemoglobin, P02238.

Searches usually finish within a minute but can take longer when NCBI is busy. The results page updates on its own; leave it open.

2

The search page, section by section

The blastp page has four sections. The defaults listed here were read from NCBI's live form. Any setting you change is highlighted on the form, and "Restore default search parameters" puts everything back.

Enter Query Sequence

  • Query box. Accessions, gi numbers or FASTA sequences. You can also upload a file.
  • Query subrange. Search with part of the query, such as one domain.
  • Job Title. A label that helps you find the search later.
  • Align two or more sequences. Tick this to compare your query with sequences you paste, instead of a database.

Choose Search Set

  • Organism limits the search to a species or group (type a name or taxonomy ID). Tick exclude to remove that group instead.
  • Exclude can drop predicted models (XM/XP accessions) and uncultured/environmental sequences.

Program Selection

  • blastp (protein-protein BLAST): the default and the standard choice.
  • Quick BLASTP (accelerated protein-protein BLAST): faster, for close matches.
  • PSI-BLAST (Position-Specific Iterated BLAST): builds a profile from the hits and searches again. See the Inside BLAST tutorial.
  • PHI-BLAST (Pattern Hit Initiated BLAST): requires a sequence pattern you supply to be part of every hit.
  • DELTA-BLAST (Domain Enhanced Lookup Time Accelerated BLAST): starts from a profile built from conserved domains, for distant homologs.

Part 1 · Four exercises

3

Exercise 1 · A first search

Do this
  1. Protein BLAST page. Query: P68871.
  2. Database: UniProtKB/Swiss-Prot. Leave everything else at its default.
  3. Click BLAST.

The Descriptions tab lists one row per database sequence. Here are the first ten and the last of our run:

ColumnMeaning
Description, Scientific NameWhat the hit is and where it comes from. Check both before trusting the annotation.
Max ScoreBit score of the best alignment (HSP) with this sequence.
Total ScoreSum of bit scores of all its HSPs. Larger than Max Score when a protein matches in several places, as with repeats.
Query CoverPercentage of your query covered by the alignments. Low cover means a partial match, often one domain.
E valueExpected number of chance hits this good in a database this size. The main filter.
Per. IdentPercent identity over the aligned region only.
Acc. Len, AccessionLength of the database sequence, and its identifier (a link to the record).

Look at the last row. Hit 100 has an E-value around 10−85, overwhelmingly significant, and yet the list stops there. That is not because nothing else matched. The default Max target sequences is 100.

4

Exercise 2 · See past the first 100

Do this
  1. Click Edit Search at the top of the results.
  2. Open Algorithm parameters and set Max target sequences to 5000. Keep everything else the same.
  3. Run the search again.
All hits with E ≤ 0.05, in rank order β-globin vs Swiss-Prot, run of 25 September 2026

Every hit is a hemoglobin chain. First come β-like chains from hundreds of vertebrates (β, δ, γ, ε). Only after about 380 of them does the first α-like chain appear. Human α-globin is hit number 419. The first 100 rows showed none of this. Nor is myoglobin anywhere in the list: at the default settings BLAST does not report it at all. Exercise 3 looks into why.

Lesson: when your question is "which families are related to my protein?", raise Max target sequences, or narrow the search with Organism, before concluding that something is absent.

5

Exercise 3 · Tune the search

Now ask a sharper question: which human proteins are related to β-globin?

Do this
  1. Edit Search. In Organism, type Homo sapiens and pick it from the list.
  2. Set Expect threshold to 10, so weak hits are shown too. Run it.
  3. Then change Word size from 5 to 3 and run again.

Three things to notice:

  • Word size matters. With the default word size of 5, only nine human hemoglobin chains are found, even at E ≤ 10. With word size 3, cytoglobin (E ≈ 10−16) and neuroglobin (E ≈ 3 × 10−4) appear. These are real, significant relatives that the faster default seeding never reached. This is the speed–sensitivity trade-off from the Inside BLAST tutorial, happening on NCBI's servers.
  • Compositional adjustment matters too. Switch it off (third column) and neuroglobin drops out again. The default adjustment usually helps for proteins of ordinary composition.
  • Myoglobin is still missing. Human myoglobin is in the database, and a full Smith–Waterman alignment with β-globin is clearly significant, yet BLAST does not report it under any of these settings. BLAST is a heuristic; not finding a relative is not proof that there isn't one. For distant relatives, try PSI-BLAST or DELTA-BLAST, or a profile HMM search.
  • The Organism filter changes E-values. Restricting to human shrinks the searched database from 487,728 to 20,526 sequences, and E-values fall to match. Human α-globin's E-value is about 2 × 10−32 in the full search and 1 × 10−33 in the human-only one. Remember this when comparing E-values between searches.

The rows below cytoglobin and neuroglobin, with E-values between 1 and 10, are unrelated proteins such as kinesins and helicases. Their short partial alignments are exactly the chance hits that an E-value near 1 predicts.

6

Exercise 4 · A plant query

Do this
  1. New search with query P02238 (soybean leghemoglobin). Database: Swiss-Prot. All defaults.

All the hits are plant globins. Other soybean leghemoglobins come first, then leghemoglobins of other legumes, then the non-symbiotic hemoglobins found in all plants. Swiss-Prot now names these by their enzymatic activity, "Anaerobic nitrite reductase", so the description alone would not tell you they are globins. The weakest hit is a moss protein, and its E-value is still about 10−23. No animal globin appears. BLAST sees the plant branch of the globin family clearly, but it cannot bridge from plants to animals. That matches what the mini-BLAST in Inside BLAST predicted.

Part 2 · The results page

7

Reading an alignment

Click a description, or open the Alignments tab, to see each alignment. This is human β-globin against human α-globin from Exercise 3. It is re-typeset here, with the same content as NCBI's text format.

Score gives the bit score and, in parentheses, the raw score. Expect is the E-value. Identities counts identical columns, Positives adds conservative substitutions (a + in the middle line), and Gaps counts gap columns. The coordinates show which part of each protein aligned. Here it is β residues 4–146 against almost all of α, with the 5-residue D-helix gap you met in the first tutorial.

8

The rest of the results page

  • Tabs: Descriptions (the hit table), Graphic Summary (where each hit aligns along your query, colored by score), Alignments, and Taxonomy (hits grouped by lineage and organism).
  • Filter Results (beside the table): narrow the displayed hits by Organism, Percent Identity, E value and Query Coverage without rerunning the search.
  • Selecting hits: tick rows, then use Download (FASTA of complete or aligned sequences, GenBank, hit tables as text or CSV), GenPept, Graphics, Distance tree of results, Multiple alignment or the MSA Viewer. That is a fast way to start the multiple alignment and phylogeny tutorials with your own data.
  • Download All saves the whole report as Text, XML, JSON, hit tables and more.
  • Edit Search reopens the form with your settings. Save Search stores the strategy, and Recent Results lists your recent searches.
  • Each search has a request ID (RID). Results are kept only for a limited time, and the page shows the expiry date. Download anything you need to keep.
  • Search Summary records the exact parameters and database version. Copy these into your notes so the search can be repeated.
9

Beyond a single blastp

  • Compare two sequences directly. Tick Align two or more sequences, paste β-globin as query and human myoglobin (P02144) as subject. Does BLAST report an alignment, and with what E-value? Compare with the database search in Exercise 3.
  • PSI-BLAST. Choose PSI-BLAST under Program Selection and run the search. The results page lets you run the next iteration using the hits that pass the inclusion threshold, and you can untick hits to keep them out of the profile. Try leghemoglobin and watch whether animal globins join in later iterations.
  • DELTA-BLAST. Uses conserved-domain profiles from the start, often reaching further than blastp in one step.
  • Other programs. The same form layout is used for blastn, blastx and tblastn, with nucleotide-specific options such as megablast, match/mismatch scores and species-specific repeat filters.

Note: what BLAST cannot tell you

  • No hit does not mean no homolog. BLAST is a heuristic. It never reported human myoglobin for a β-globin query (Exercise 3), even though myoglobin was in the database and the two proteins are homologs. In the command-line tutorial, β-globin also fails to find E. coli's flavohemoglobin, although neuroglobin finds it.
  • Settings change what is found. Cytoglobin and neuroglobin appeared only at word size 3. The hits you see depend on word size, matrix, filters and compositional adjustment as well as on the sequences.
  • E-values belong to one search. They scale with database size and depend on the settings, so an E-value means little without the database and parameters it came from.
  • Lists are cut off. The Max target sequences default of 100 hid 639 of the 739 significant β-globin hits (Exercise 2).
  • The database is not everything. Swiss-Prot, core_nt and nr are subsets of what exists. No single database holds all of GenBank (section 10).
  • Alignments are local. A significant hit may cover one domain, not the whole protein. Neuroglobin aligns only to residues 28–129 of the 396-residue Hmp, its globin domain. Check query coverage before calling two proteins the same.
  • Names are borrowed. Hit descriptions come from the database records, not from BLAST. Many leghemoglobin hits are named "Anaerobic nitrite reductase" (Exercise 4).
  • For distant relatives, go further. Profile methods (PSI-BLAST, HMMER) and structure comparison detect relationships that pairwise BLAST misses. The course tutorials on HMMER and structural alignment show them at work on these same globins.
10

Can BLAST search all of GenBank?

Not in a single search. NCBI's own search form says so: "No BLAST database contains all the sequences at NCBI. BLAST databases are organized by informational content (nr, RefSeq, etc.) or by sequencing technique (WGS, EST, etc.)." The default nucleotide database covers only a small part of GenBank.

How big is "everything"? bases and sequence counts

GenBank figures are from NCBI's GenBank and WGS statistics for Release 273 (August 2026). The core_nt figures are from a real blastn search on 25 September 2026. core_nt also includes RefSeq and other NCBI sequences, so the comparison is approximate. The gap is still about 50-fold.

Why no single database holds it all

  • Some data types are separate databases. Whole-genome shotgun contigs (wgs), transcriptome assemblies (TSA), expressed sequence tags (est), genome survey sequences (gss), unfinished high-throughput genomic sequences (HTGS), patent sequences (pat) and raw reads (SRA) are each separate choices in the blastn Database menu. WGS is the biggest part of GenBank by far, and NCBI asks you to limit WGS and TSA searches by organism, BioProject or WGS project.
  • The default is a curated core. blastn searches the Core nucleotide database (core_nt) by default. Nucleotide collection (nr/nt) is still on the menu, but since September 2024 NCBI sends non-interactive searches of nt (scripts and the URL API) to core_nt instead. We saw this ourselves: an API request for nt came back from core_nt, with 131,070,239 sequences either way.
  • Identical sequences are merged. core_nt and nr are non-redundant, so identical sequences share one entry, named after one representative record. Your favourite accession may be hidden inside another record's entry. On the web, the alignment view has a link that lists all the merged records.
  • Only released data. A sequence you submitted appears only after NCBI releases it.
  • Proteins live elsewhere. GenBank is a nucleotide archive. The protein translations of its coding regions are searched through protein databases such as nr, which merges identical proteins, and ClusteredNR, which groups similar ones.

So a thorough search can take several searches. Start with core_nt. If the organism has a draft genome or transcriptome, repeat the search against wgs or TSA limited to that organism. Report every database you searched. On the command line you can download BLAST databases or build your own, but even NCBI does not offer one file that holds all of GenBank.

Web versus command line

The web defaults differ from BLAST+ on the command line. NCBI's BLAST FAQ says that to reproduce web blastp results with BLAST+, you should add -evalue 0.05 -max_target_seqs 100 -seg yes. Otherwise BLAST+ uses its own defaults (for example an E-value cutoff of 10). Also match the word size, matrix, gap costs and database version shown in the Search Summary.

The searches on this page were submitted through NCBI's BLAST URL API, a programmatic route to the same service, with the parameters listed below. The web page and API use the same servers and databases.

Check yourself

1. Your search returns exactly 100 hits, all with E-values below 10⁻⁸⁰. What should you suspect?

The Max target sequences cap (default 100) has cut the list off. Many more significant hits probably exist. Raise the limit or narrow the search.

2. Why did cytoglobin and neuroglobin appear only after changing word size from 5 to 3?

BLAST only extends alignments that start from word hits. Longer words need longer exact-ish matches, so distant relatives produce too few seeds. Smaller words seed more alignments, at the cost of speed.

3. The same α-globin hit has E = 2 × 10⁻³² in one search and 1 × 10⁻³³ in another. Is one wrong?

No. The second search was limited to human sequences, so the database was about 24 times smaller and E-values scale down accordingly. E-values are only comparable between searches of the same database.

4. BLAST did not report myoglobin for a β-globin query. Can you conclude the two are not homologous?

No. BLAST is heuristic and failing to find a hit is not evidence of absence. Myoglobin and hemoglobin are well-established homologs (same fold, same heme-binding histidines), as the earlier tutorials showed with full dynamic programming, profile methods and structure.

5. Many leghemoglobin hits are named "Anaerobic nitrite reductase". What does that teach you about descriptions?

Names describe what a protein does or what was measured, not necessarily its family. Use the alignment, E-value and coverage to judge homology, and look at the record to understand the name.

6. You want to rerun a colleague's web search next year. What do you need from them?

The query, program, database and its date or version, and every parameter from the Search Summary: word size, matrix, gap costs, compositional adjustment, filters, Expect threshold, Max target sequences, and any Organism limits.

7. A classmate says "I BLASTed my sequence against all of GenBank and found nothing." What should you ask?

Which database did they search? The default, core_nt, holds about 131 million sequences, a small part of GenBank. WGS and TSA assemblies, ESTs, HTGS, patents and SRA reads have to be searched separately, and WGS and TSA usually need an organism or project limit. "No hit in core_nt" is not the same as "no hit in GenBank".
