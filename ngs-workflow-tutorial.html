Stage 1 of 5

Library preparation

Turning a genome into millions of sequencer-ready molecules

A human genome is about 3.1 billion base pairs long, but a short-read sequencer reads only 100–300 bases at a time. So the first job is to break purified DNA into fragments of a predictable size and attach synthetic adapters to both ends. The collection of adapter-tagged fragments is called a library.

Stage 2 of 5

Cluster generation

Making each molecule bright enough to see

A single DNA molecule gives off too little light for a camera to detect. The library is washed over a glass flow cell whose surface is coated with two kinds of oligos that match the P5 and P7 adapters. Each molecule that lands is copied in place by bridge amplification: the strand bends over, anneals to a neighbouring oligo, and is copied again. After about 35 cycles each seed becomes a cluster of roughly 1,000 identical copies.

Load too little library and the flow cell is wasted. Load too much and clusters grow into each other. A camera cannot separate overlapping clusters, so those polyclonal spots fail the chastity filter and are thrown away.

Stage 3 of 5

Sequencing by synthesis

One base, one image, one cycle at a time

A primer binds the Read 1 site and polymerase extends it using nucleotides that carry two modifications: a colour-coded fluorescent dye and a reversible 3′ terminator. The terminator lets only one base be added per cycle. The instrument images the flow cell, cleaves off the dye and terminator, and repeats. The colour of each cluster in each image is that cycle's base.

Chemistry is not perfect. In each cycle a small fraction of molecules in a cluster fail to extend (phasing) or jump ahead (pre-phasing). The cluster's signal gets muddier as the read goes on, which is why quality falls toward the 3′ end.

Stage 4 of 5

Reads & quality

What the sequencer hands you: FASTQ

Base calls are written to a FASTQ file, four lines per read: an @ header, the sequence, a + separator, and a quality string with one character per base. Each character encodes a Phred score, Q = −10 log10(Perror), stored as the ASCII character with code Q + 33.

Stage 5 of 5

Alignment & variant calling

From millions of reads to a genotype

An aligner such as BWA-MEM or Bowtie2 finds where each read best matches the reference genome and writes the result to a SAM/BAM file. Stacking the aligned reads gives a pileup. A variant caller looks at each position and asks which genotype best explains the bases it sees, allowing for sequencing errors. Results go into a VCF file.

The number of reads covering a position is its depth. A single mismatched base is more likely an error than a variant. A heterozygous SNP should show up in about half the reads.

Wrap-up

Short reads and long reads

The same workflow shape, different trade-offs

Short-read (Illumina SBS)

  • Reads of 50–300 bp, often paired-end
  • Per-base accuracy > 99.9% (Q30+) for most bases
  • Billions of reads per run; lowest cost per base
  • Struggles with repeats, large structural variants, phasing haplotypes
  • Workhorse for exomes, RNA-seq, ChIP-seq, population genomics

Long-read (PacBio HiFi, Oxford Nanopore)

  • Reads of 10 kb to over 1 Mb from single molecules
  • HiFi reaches Q30+; nanopore accuracy now ~Q20+ with current chemistry
  • No cluster amplification, so base modifications like 5mC can be read directly
  • Spans repeats and resolves structural variants and haplotypes
  • Used for telomere-to-telomere assemblies and clinical SV detection

Simulations here use simplified models for teaching: fragment sizes are log-normal, cluster growth is logistic, and phasing error is a single per-cycle rate. Real instruments model these with far more parameters.
