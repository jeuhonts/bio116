## DNA Sequencing & Genome Assembly Lab

Open [`sequencing-assembly/index.html`](sequencing-assembly/index.html) in a web browser: six interactive stations built on the human HRAS sequence in `triplets.txt`. Students run a Sanger capillary and read a tumour chromatogram (HRAS G12V), watch Illumina sequencing-by-synthesis cycles and Phred scores, simulate shotgun coverage (Lander–Waterman), assemble reads by overlap–layout–consensus, build de Bruijn graphs at different k, and see how long reads resolve the HRAS1 minisatellite. Also covers N50. Includes 17 self-checking questions and tasks.
