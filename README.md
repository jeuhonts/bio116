## Genome Browser Lab

Open [`genome-browser/index.html`](genome-browser/index.html) in a web browser: an interactive genome browser built on the human HRAS genomic sequence in `triplets.txt`, with 11 guided missions (navigation, base-level zoom, splice sites, oncogenic and synonymous variants, strand orientation, CpG island, HRAS1 minisatellite, BED vs 1-based coordinates).
