## Eukaryotic Gene Finding Lab

Open [`gene-finding/index.html`](gene-finding/index.html) in a web browser: six interactive stations that find the human HRAS gene in the 10,309-bp entry from `triplets.txt` (same numbering as the genome browser and sequencing labs), with the RefSeq annotation (NM_005343 / P01112) as the answer key. Students run a six-frame ORF scan and see why "longest ORF" fails in eukaryotes, score splice sites with position weight matrices and sequence logos, plot three-frame codon-usage coding potential, assemble a gene model from candidate exons while tracking intron phase, tune a GENSCAN-style dynamic-programming parser and measure sensitivity/specificity, and compare the prediction with simulated RNA-seq junction evidence. Includes 22 self-checking questions and tasks.
