# bio116
Bioinformatics

## Biology primer

`index.html` is a self-contained interactive review of the biology behind bioinformatics
(cells, DNA, chromosomes, genomes, the central dogma, the genetic code, gene expression and
regulation, protein structure and function, metabolism, variation, alignment, phylogenetics,
sequencing data), written for life-sciences students reviewing and computer-science students
meeting it for the first time. Open it in any browser; no build step or server is needed.

Chapter 14 is a workbench that analyses the sequence in `triplets.txt` (GC content, six-frame
ORFs, motif search). The file lists one 10,309 bp human sequence three times, split into codons
from bases 1, 2 and 3 (its three forward reading frames).
